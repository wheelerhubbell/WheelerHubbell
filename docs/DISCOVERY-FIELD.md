# WHP Standing first-public discovery boundary

The immutable Mark, separately signed current registry and separately signed current capability resolution are distinct cryptographic objects. `docs/FIRST-PUBLIC-V1.md` defines their exact meanings. A valid historical signature is never current standing, and a current service origin never rewrites historical meaning.

A Mark embeds its exact profile and public semantic contract and commits to the independent verifier. Its immutable capability and resolution identity lead to a current root-authorized DISCOVERY statement. That fresh statement binds current service/profile/OpenAPI/purchase locations and immutable content hashes. The stable resolution may direct a consumer to a new service origin without changing old Mark bytes. The same root must authorize the current resolution; automatic root replacement is not admitted.

The generic cold reader `scripts/cold-agent.py` contains no provider names, addresses, source paths, profile IDs or repository imports. It accepts one input file. A receives only a completed Mark. B receives only an external object, contemplated action and neutral need interface with a generic catalog entrypoint. C verifies a first Mark before processing a distinct unsupported object/action through the same neutral interface. All HTTP addresses and protocol vocabulary are learned from these inputs and returned public documents.

The neutral catalog fixture has incompatible entries as well as a compatible entry with an arbitrary directory name. Matching uses capability class, required properties, scope and jurisdiction, not WHP branding. Independent alternatives are tested. This is bounded local discovery, not proof of external public-directory registration or open-internet indexing.

Downloaded verification code is hash-checked against root authorization before execution in a generic OCI image with network disabled, a read-only root filesystem, no producer files or secrets, dropped capabilities and a non-root UID. The image contains only Python and generic cryptographic/schema libraries. The consumer's ephemeral Ed25519 HTTP identity is not a wallet. An explicitly unadmitted self-attestation probes current terms; it never creates source authority or guarantees a Mark. Each next purchase stops at a real x402 HTTP 402 response with signed exact terms. No next payment is signed or settled.

TEST_SELF_CONSISTENT_ROOT is not institutional admission. The cold TEST paths do not authenticate a legal institution, assert production authority or prove a sale. LIVE needs an independently admitted root and the actual production rail, deployment and outside buyer.

Existing MCP, Bazaar, API-catalog, OpenAPI, HTML, robots and repository descriptions remain provider discovery aids. Their metadata does not establish third-party catalog acceptance. Historical external-surface research and the earlier carrier implementation are preserved at `evidence/development/discovery-107-FIELD.md`; its old carrier is not a public verifier fallback.

Executed evidence belongs under `evidence/public-v1/`. Its source manifest, fresh TAP output, separate-process HTTP/storage proof, Python replay, neutral catalog traces and A/B/C reports distinguish TEST propagation from production-only predicates.
